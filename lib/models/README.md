# Modele danych

Modele są niezależne od UI i mają format `toMap`/`fromMap`, dzięki czemu można je bezpośrednio podłączyć do adaptera Firebase Firestore albo Supabase.

- `AquariumModel` opisuje zbiornik.
- `WaterTestModel` przechowuje pomiary wody.
- `MaintenanceModel` przechowuje historię podmian i pielęgnacji.
